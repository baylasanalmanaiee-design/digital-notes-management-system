# Digital Notes Management System

A team-based academic software engineering project developed as part of a university course at Qassim University.

The project focuses on the analysis and design of a Digital Notes Management System that enables users to create, organize, search, share, and manage digital notes in a structured environment.

## Project Scope

The project covers the software engineering analysis and design process, including:

- Software Requirements Specification (SRS)
- Software Design Description (SDD)
- Functional and non-functional requirements
- Use case modeling
- UML diagrams
- System architecture and design
- Agile development process

## Key Features

The proposed system includes:

- Creating and managing digital notes
- Organizing notes using folders and tags
- Searching and filtering notes
- Sharing notes with other users
- Cloud synchronization
- Real-time collaboration
- User account management
